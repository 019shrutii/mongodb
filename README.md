# Student Performance Analytics Dashboard

The Student Performance Analytics Dashboard is a web-based application developed using Python, Flask, and MongoDB to manage and analyze student academic performance. It displays important statistics such as total students, average marks, attendance rates, and students with low attendance through summary cards and interactive charts.

The application allows users to add, search, and delete student records, while MongoDB stores the data for efficient retrieval and management. It helps users understand academic performance across different departments and subjects through a simple, user-friendly dashboard.

**Technologies Used:** Python, Flask, MongoDB, PyMongo, HTML, CSS, JavaScript, and Chart.js.

**Key Features:**
- Student record management
- Academic performance and attendance analytics
- Interactive charts for subject and department analysis
- Student search and record deletion
- MongoDB database integration
- Web-based dashboard for data visualization
